# 🐶 Flappy Doggy OP

A fun and challenging flying dog game! 🐶🌀

## 🎮 Play the Game

### 👉 [PLAY FLAPPY DOGGY OP](https://shubhneet-singh.github.io/Flappy-Doggy-OP/)

## ⭐ Features

- 🐶 Flying dog gameplay
- 🌀 Dodge vacuum cleaners
- 🪙 Collect coins
- 🛡️ Buy shields
- 🎨 Unlock different dog skins
- 🏆 High score system
- 📱 Works on mobile and desktop
- 💾 Saves progress in your browser

## 🎮 Controls

**Desktop:** Click or press **Space**

**Mobile:** Tap the screen
